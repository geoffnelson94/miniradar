Requirement ID:
    TRK-REQ-001

Title:
    Detection Processing

Requirement:
    The radar software shall accept valid radar detections
    and use them to update the track state estimate.

Rationale:
    Tracking requires measurements from the detection subsystem.

Verification:
    Test

Verification Method:
    A test shall provide a known sequence of detections and
    verify that the expected track state is produced.
